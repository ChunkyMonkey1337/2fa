📦 Зависимости и требования
Для работы системы требуются базовая Linux-среда (тестировалось на Debian 11/12 и Ubuntu 20.04/22.04/24.04). Установщик загружает всё необходимое автоматически.
1. Системные пакеты (Linux)
python3 — основной интерпретатор.
python3-venv — для создания изолированного окружения (обязательное требование в современных Ubuntu/Debian, чтобы не сломать системный Python).
python3-pip — пакетный менеджер для установки библиотек.
libpam-modules — ради модуля pam_exec.so (обычно установлен в ОС по умолчанию), который позволяет SSH вызывать сторонние скрипты.
systemd — для запуска Telegram-бота как фоновой службы.
openssh-server — сам SSH-сервер.
2. Библиотеки Python (устанавливаются в venv)
python-telegram-bot — мощный асинхронный фреймворк для работы самого демона (слушает кнопки и команды).
requests — для быстрой синхронной отправки сообщений в Telegram API из скрипта перехватчика и для получения GeoIP-информации.
python-dotenv — для безопасного и удобного чтения переменных из файла .env.
3. Сетевые требования
Доступ к https://api.telegram.org (порт 443) с вашего сервера.
Доступ к http://ip-api.com и https://api.ipify.org (для получения GeoIP и внешнего IP сервера, опционально, при недоступности не сломает вход).
